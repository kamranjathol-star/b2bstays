Cookie Policy

Last updated:

1. Cookies

This website does not set any cookies.

2. Browser storage

The website stores one small item in your browser so that it remembers the language you chose. It is not used for tracking and is never sent to us.

NamePurposeLastsWho sets it
b2b-langRemembers your language choice (English or Arabic)Until you clear this site’s dataThis website (first party)

3. Third parties

This website does not use analytics, advertising or social-media trackers, and does not load fonts or scripts from third parties. If we add any of these in future we will ask for your consent first and update this page.

4. Managing storage

You can clear this site’s stored data at any time in your browser’s settings. The website will still work; it will simply show English until you choose a language again.

For more on how we handle personal data, see our Privacy Policy.
